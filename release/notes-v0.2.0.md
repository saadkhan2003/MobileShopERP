# Mobile Shop ERP 0.2.0

Linux desktop release with local SQLite storage. Includes product and IMEI inventory, purchases, sales and customer returns, repairs, installments, payments, ledgers, reports, cash closing, PDF invoices and repair job cards, external backups, and global shop settings.

Use the AppImage for in-app signed updates. The `.deb` is available for manual installation. Back up your existing shop database before replacing an older build.
